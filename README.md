#  Bank API Tests

Автоматизированное тестирование банковского REST/WebSocket API и стенд для тестирования безопасности **GraphQL API** с использованием **Postman / Newman**, **Test IT** и **GitHub Actions (CI/CD)**.

##  Структура проекта

### 1. Основной REST / WebSocket сервер (корень репозитория)
* `server.js` — тестовый банковский сервер на Node.js (с поддержкой WebSocket `ws`).
* `bank-api.json` — коллекция API-запросов и автотестов (экспорт из Postman).
* `bank-env.json` — переменные окружения для запуска тестов.
* `.github/workflows/tests.yml` — конфигурация CI/CD для автоматического прогона тестов в GitHub Actions при каждом `push` в `main`.

### 2. GraphQL-сервер и стенд уязвимостей (`graphql-server/`)
Отдельный модуль для отработки тестирования функциональности и безопасности GraphQL API:
* `server.js` — GraphQL-сервер с намеренно заложенными уязвимостями (**IDOR**, **BOLA**, **SQL Injection**, **Race Condition**).
* `db.js` — инициализация и работа с локальной базой данных.
* `race-test.js` — скрипт для проверки уязвимости состояния гонки (Race Condition) при параллельных запросах.
* `VULNERABILITIES.md` — документация с разбором реализованных уязвимостей и сценариев их эксплуатации.
* `postman/` — коллекции запросов и автотестов Postman для проверки GraphQL API.
* `testit/` — материалы и тест-кейсы для интеграции с системой управления тестированием **Test IT**.

##  Как запустить локально

### Запуск основного банковского API и тестов
1. **Установите зависимости и Newman:**
   ```bash
   npm install
   npm install -g newman
   ```
2. **Запустите банковский сервер** (в первом окне терминала):
   ```bash
   npm start
   ```
3. **Запустите автотесты** (во втором окне терминала):
   ```bash
   npm test
   ```

### Запуск GraphQL-сервера
1. **Перейдите в папку модуля и установите его зависимости:**
   ```bash
   cd graphql-server
   npm install
   ```
2. **Запустите GraphQL-сервер:**
   ```bash
   node server.js
   ```
3. **Запустите тест на Race Condition** (в отдельном окне терминала из папки `graphql-server`):
   ```bash
   node race-test.js
   ```
